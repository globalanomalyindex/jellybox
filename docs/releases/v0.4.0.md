# JellyBox v0.4.0

First public preview of JellyBox by Christopher Robin Fiore: a design-system study of density, connected motion, color and light.

- Three working tools gather into shared jelly windows; inner density folders retain steady text and native targets.
- Movable light, Spectral pigment transitions, motion/material controls and explicit browser-local saved looks.
- Hierarchical page arrival, persistent design-story chapters and a guarded progressive scroll edge.
- Experimental React foundation: sixteen CSS/SVG controls, optional shared Three renderer, types, semantic tones and reusable motion/color helpers.
- MIT code, lockfile-based builds, Node 24 CI and GitHub Pages deployment. The commercial story font is deliberately excluded from source/packages; public clones use the fallback.

The React archive is attached with SHA256SUMS. It is distributed through GitHub Releases, not npm.

These are implemented mechanisms and design hypotheses. The optics are authored approximations; no validated fluid physics, universal 60fps, blanket accessibility certification or proven usability benefit is claimed. See docs/VERIFICATION.md.
