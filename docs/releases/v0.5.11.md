# JellyBox v0.5.11

The inner control now owns attention. While a slider or other enabled control is hovered, focused or dragged inside an open folder, the folder's extra hover gathering settles back through the existing240ms response. Its structural density stays visible. The invitation can return on the header or blank material once no child remains engaged.

Main and story folders share this rule. Compound sliders reuse their existing focus and gesture ownership, including captured scrubbing, rather than adding another tracker. Text, values and click targets stay fixed. CSS fallback follows the same priority. No new renderer resource, animation clock or public prop is introduced.

Three experts agreed the policy and cross-reviewed the implementation. Validation:158 component/model tests plus4 adapter checks, strict consumer types, site/library builds and packed core/optional-renderer consumers. Native browser checks covered keyboard handoff, fixed204×44px disclosure, value scrubbing/release/reset, clean close/reopen, story child focus, CSS fallback and a390px embedded layout without horizontal overflow. Disabled/inert and pause/reduced-motion behavior were source/model reviewed; this pass does not establish physical touch or assistive-technology coverage. The design detector reported no findings or new suppressions.
