# JellyBox v0.5.3

Activity now concentrates and settles into its result with a small tactile release.

- The full current draws inward instead of fading away. A damped material response retains its momentum through concentration, compression and recoil. Shape, optical normals, thickness and receiver lighting share that strain. Labels and the 208 px native target remain anchored.
- Body and internal current follow the same 480 ms Spectral sample. The current reaches the semantic destination before the spatial tail settles, preventing a blue flash during success/failure recoil. Retry and Cancel retain displayed pigment, shape and velocity. Task state is never delayed.
- Adaptive ink uses true black/white and no longer preserves a weaker failing color. The activity material has a quieter reading normal/roughness response, without an extra face, text outline or backing. Active/settling labels use the existing bounded 30 Hz sampling priority; ordinary labels remain at 10 Hz.

Validation: 122 component/model tests plus four static-adapter tests, strict consumer types, site/library builds, packed-package consumer and source hygiene. Added behavior coverage checks compression/release, exact settling, frame-rate bounds, retained interruption momentum, reduced motion and internal-pigment endpoint continuity. Native browser checks cover blue work, green success, amber warning, red failure, Cancel/retry and fixed label/target bounds. Sampled contrast readings describe checked states, not exhaustive accessibility certification. Optics remain authored real-time approximations.

No runtime dependency was added. The separately licensed story font remains excluded from source and packages.
