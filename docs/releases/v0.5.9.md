# JellyBox v0.5.9

Slider bulbs and Color-window choices now use a filled density shoulder inside the existing jelly instead of gray DOM strokes. Thickness, refraction normals and same-pigment absorption supply the boundary, with a stronger small-thumb path to retain separation. Larger reading centers stay quiet. The existing connected carrier still owns selection; approach and color use their current shared responses.

CSS-only controls receive a broad shaded approximation. Value buttons reset native button chrome, and rendered thumbs no longer have an opaque white pseudo-face covering the material. Native color wells keep their picker with a compatible skin. Text, labels, native targets, checks, blue keyboard focus and forced-color boundaries remain independent.

Three experts agreed one contract before building and cross-reviewed the implementation. Validation:157 component/model tests plus4 adapter checks, strict consumer types, site/library builds, packed core/renderer consumers and source hygiene. Native checks covered default/lamp-off material, palette preview and focus, direct slider keys, motion-off input, a390px embedded browser viewport and standalone CSS controls with disabled states. Observed Color-label readings ranged from10.39:1 to14.69:1 in these captures; lamp-off value labels measured12.83:1. These are bounded readings, not universal contrast or physical-material guarantees.
