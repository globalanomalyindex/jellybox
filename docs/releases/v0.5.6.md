# JellyBox v0.5.6

The design story now demonstrates the system as you read.

- A persistent indeterminate loader sits beside automatic loading-to-success, warning and failure examples. Results hold long enough for gathering, lighting and the settling jiggle to read.
- All four canonical Bézier responses appear together in a tidy responsive grid, sharing one repeat period and origin while retaining their real response speeds. The revealed path and marker stay aligned at different widths.
- Density, pigment grouping and the ambient desktop lamp demonstrate automatically. The density dropdown and its contents remain optionally playable; the main three-tool experiment stays interactive.
- One visible-time lifecycle freezes offscreen/hidden playback without catch-up. Motion-off, Still and reduced motion show clear static examples. Native text stays steady, passive specimens add no focus stops or announcements, and no new renderer or dependency was added.

Validation:142 component/model tests plus4 static-adapter tests, strict types, site/library builds and packed-consumer checks. Three experts agreed the shared playback/material/layout policy and cross-reviewed the integrated changes along Spec and Standards axes. Native desktop/mobile checks inspect the actual rendering and behavior. Authored demonstrations are not physical simulation, a real application task duration, or a blanket accessibility/performance claim. The licensed font remains excluded from source/packages.
