# JellyBox v0.5.0

The design story now uses the same rendered material and controls as the experiment, with working examples of density, color membership, activity and guided light.

- Bézier diagrams loop only while visible, with canonical timing and endpoint holds. No replay buttons or instructional filler. Continuous-motion off, hidden documents and reduced motion stop playback.
- A real density folder gathers controls from its parent material. A Structure slider adjusts concentration; included items retain native state. Shared-pigment groups support join, preview, update, revert and separation.
- Adaptive ink samples actual rendered backgrounds in one bounded asynchronous GPU batch, chooses dark/light text, and uses a thin glyph halo where mixed highlights require it. Native text remains above the canvas; no opaque inner pill is added.
- New public `JellyActivityButton` accepts application-owned loading, progress, success, warning and failure states. A clearly labeled simulated task demonstrates determinate/indeterminate work, cancel and retry using rendered pigment motion.
- Task spotlight previews follow pointer/keyboard focus while a check preserves committed selection. The story light shares the page renderer and releases the main lamp offscreen.
- Visible surfaces share the existing pool and light. Offscreen hero optics are culled, point-light normalization remains anchored, and story casts stay compact around reading areas.

Validation: 116 component/model tests, four static-adapter tests, strict TypeScript consumer, site/library builds, packed-package consumer and public-source scan. Native checks covered dark/light ink, light off, chart pause/resume/offscreen, group commit/revert, all task outcomes/cancel, spotlight keyboard preview, folder retention and a 375px layout. These checks do not establish universal accessibility, physical-simulation accuracy or a measured usability improvement.

The commercial story font remains excluded from source and package archives; separately licensed deployment builds may supply it. No new runtime dependency or Tailwind/shadcn scaffold is required for the translated activity pattern.
