# JellyBox v0.4.1

Source-hygiene patch for the first public preview. The website and React API keep the same behavior.

- Removed a local source-file path embedded in the supplied PNG’s provenance metadata, preserving its compressed image pixels exactly. The editable SVG, source provenance and attribution remain.
- Release checks now inspect every tracked asset for common machine-specific paths, in addition to excluding licensed fonts and private/generated files.
- Includes the same reproducible React package, Node 24 checks and Pages deployment as v0.4.0.

The installable React archive and SHA256SUMS are attached. No commercial font is included.
