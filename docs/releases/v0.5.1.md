# JellyBox v0.5.1

Solid lettering, swirling activity and synchronized motion examples.

- Removed glyph outlines, text shadows and icon halos from the shared ink policy. Text still chooses dark/light ink from rendered material samples; actual sampled ratios remain available. The compatibility `halo` result is deprecated and always false.
- Loading now twists two broad density lobes through the button with a slow breath. Absorption, optical normals, thickness and receiver lighting follow the same field. Known and unknown progress share the circulation; native percentage/progress semantics still report application-owned values. Pause and reduced motion stop the travel.
- The curve draw, marker and actual rendered jelly preview share one explicit timeline origin. The preview stretches and settles, with Recoil selected initially. Shorter loop holds keep the response visible without replay controls. Only the moving preview is remeasured; the scene retains one WebGL context and its existing surface budget.

Validation covers the ink policy, full-body activity model, native busy/progress states, loop timing/overshoot/seams, strict types, site/library builds, packed consumer and source hygiene. The animated loading task remains a labeled simulation. Sampled contrast and authored optics are not exhaustive accessibility or physical-simulation certifications.

The source/package exclude the separately licensed story font. No runtime dependency was added.
