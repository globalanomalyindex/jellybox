# JellyBox v0.5.14

Slider hover now follows the round bulb and numeric value bubble. Labels, empty rail and row space remain quiet, while native rail clicks, dragging, label focus and keyboard controls keep working. The same boundary applies to the live study, optional renderer and CSS fallback.

The shared slider owns its hover/press state, with the existing jelly gather, settling and exit grace. Thumb assistance begins inside the bulb zone. If accepted click travel brings a bulb beneath a stationary cursor, its hover updates with that value.

Validation: 173 component/model tests plus 4 adapter checks, strict types, site/library builds, packed consumers and source hygiene. Native checks covered hover boundaries without focus/value changes, keyboard input, rail travel, outside scrub release and disabled/core-only behavior. Final review also corrected a batched entry/exit release race. No new design-detector findings or suppressions. Broader device and accessibility evaluation remains necessary.
