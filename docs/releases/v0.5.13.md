# JellyBox v0.5.13

Density now travels from a folder into the control you approach, then flows back when you leave. A shallow donor area, moving crest and receiving shoulder share one displayed material state, so their lighting, pigment and refraction move together. Text, values and native click targets remain anchored. Interrupted handoffs continue from the material already on screen.

The main experiment and design story use the same registered controls and bounded renderer. Explore and Material now explain the shared-material principle directly in the live demo. The optional renderer API accepts a registered receiver target; core controls and CSS fallback remain usable without Three.

Three experts agreed and cross-reviewed the change. Validation: 173 component/model tests plus 4 adapter checks, strict consumer types, site/library builds, packed-package consumers and source hygiene. Native desktop checks covered travel, return, control-to-control handoff, steady targets, keyboard input, scrub release and story behavior; a 390 px embedded layout was inspected. Impeccable reported no findings or new suppressions. The optical behavior is an authored approximation, with broader device and usability evaluation still needed.
